# 강금옥 쭈꾸미 마케팅 광고 운영 제안

## GitHub Pages 배포
1. ZIP을 압축 해제합니다.
2. 저장소 최상위(root)에 `index.html`과 `assets/` 폴더를 업로드합니다.
3. GitHub 저장소의 Settings → Pages에서 배포 브랜치와 `/ (root)`를 선택합니다.
4. 저장 후 생성된 GitHub Pages 주소로 접속합니다.

## 조작
- 오른쪽 화살표 / 스페이스 / Page Down: 다음 슬라이드
- 왼쪽 화살표 / Page Up: 이전 슬라이드
- 모바일: 좌우 스와이프
- 화면 하단 화살표 버튼도 사용할 수 있습니다.

## 포함 자료 및 수치 기준
- 제공된 2026년 8월·9월 네이버 키워드 광고 CSV 리포트
- 제공된 2026년 9월 Meta 성연령 리포트
- 로고는 투명 여백을 정리하고 원본 비율을 유지해 배치했습니다.
- 네이버 리포트에는 비용이 0원으로 표시된 브랜드검색 캠페인의 전환매출이 포함되어 있어 전체 합산 ROAS를 성과 수치로 단정하지 않았습니다.
- Meta의 구매 및 구매 전환값은 플랫폼 보고값이며, 강금옥 자체 실적이 아닌 유사 식품 카테고리 참고 사례로 표시했습니다.
